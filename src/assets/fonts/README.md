# Anton

Display-Schrift für Spieltitel und Bildschirm-Überschriften.

- Quelle: Google Fonts, Familie `Anton`, v27, Subset `latin`
  (`U+0000-00FF` — deckt die deutschen Umlaute und ß ab).
- Datei: `https://fonts.gstatic.com/s/anton/v27/1Ptgg87LROyAm3Kz-C8.woff2`
- Lizenz: SIL Open Font License 1.1, siehe `Anton-OFL.txt`.

Wird lokal mitgeliefert, nicht vom CDN geladen: Die App läuft offline
und als native App ohne Netzzugriff.
